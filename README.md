# Enterprise-Style Linux Infrastructure Lab

## Rocky Linux + Debian | Linux Administration, Cybersecurity & GRC

A hands-on cybersecurity and Linux administration project designed to simulate a small enterprise infrastructure using two Linux servers.

The project focuses on **secure infrastructure design, access control, network security, centralized logging, backup and recovery, security monitoring, and GRC risk assessment**.

---

## 📌 Project Overview

The infrastructure consists of two Linux servers with clearly separated responsibilities:

- **Rocky Linux** → Web / Application Server
- **Debian Linux** → Centralized Logging / Management / Backup Server

The objective is not only to configure the servers, but also to evaluate the security risks associated with the infrastructure, implement security controls, test those controls, collect evidence, and document the remaining residual risk.
